# CareerBridge 🎓

A web application that bridges communication between
students, faculty, and college staff.

## 💡 About
CareerBridge solves the communication gap in colleges by
providing a unified platform where students can connect
with faculty and staff seamlessly.

## 🚀 Features
- Student portal to view notices and updates
- Faculty dashboard to post announcements
- Staff management interface
- Role-based access for students, faculty, and admin

## 🛠️ Tech Stack
- **Frontend:** Next.js, TypeScript, Tailwind CSS
- **Database:** Prisma ORM
- **Styling:** Tailwind CSS, PostCSS

## 📦 Getting Started
```bash
npm install
npm run dev
```
Open http://localhost:3000
